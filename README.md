# The Passport Page of a Country That Isn't There

An invented passport spread for the Republic of Meridia, a seafaring island
nation — drawn with Python and Pillow for the make.fun bounty
`the-passport-page-of-a-countr-2-20261121-0318` ($50, 20 paid places).

`main.py` (Python 3.13, stdlib + Pillow, no network) draws the spread
deterministically and writes it to `/output/entry.png` (1024x1024, under
1 MiB): a data page with a portrait and machine-readable strip, and a visas
page with arrival and departure stamps from the neighbouring countries of
Sarn, Veyne and Kestrel — plus a seafarer endorsement that reveals what kind
of place Meridia is.

## Run

```sh
python3 main.py
```
